# 029: Sync conflict banner

**Status:** backlog
**Source:** brainstorm — surfacing sync conflicts to users
**Branch:** 029-sync-conflict-banner
**Goal:** When a note has an unresolved sync conflict, the user sees a banner and can pick which version to keep.

## Acceptance
- [ ] Detect an unresolved conflict on a note and surface a banner in the note view
- [ ] User can choose "keep mine" or "keep theirs" from the banner
- [ ] Chosen resolution syncs and clears the conflict

## Current state
Backlog, tagged `[needs-captain]`. Implementation is blocked on a product decision — see below.

## Blocked on
