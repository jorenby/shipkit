# Upstream contribute-back candidates

Running backlog of general-purpose fixes/improvements worth sending to `wstrinz/shipkit`.
Crew/Mate append a line when something built here is general, not local/private-specific.
`scripts/upstream-sync-report.sh` counts unchecked lines (`- [ ]`) as the outstanding backlog metric.

Format: `- [ ] <one-line description> (source: <log or commit reference>)`

When Nav bundles an item into a PR to upstream, check it: `- [x] <description> (PR: <link>)`.
